# MasioASM
MasioASM is a custom macro preprocessor for `.masio` files.
It transforms MasioASM code into standard NASM code.
Using macros, it reduces code and keeps it simple and gives extra functionality (soon more).

## Project Goals
- Understanding Assembly
- Reducing Code while keeping functionality
- Building something in MasioASM
- Make learning assembly easier

## Feature
Macros (soon more)
