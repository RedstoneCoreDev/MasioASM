Getting Started

MasioASM is designed to make learning assembly easier by shortening tedious register setups, function framing, control structures, and boilerplate while outputting standard NASM code.

Linux-First Project: MasioASM is natively targeted for x86_64 Linux systems. Build tools or wrappers for Windows or macOS are community-driven or AI-generated wrappers.

Features & Keyword Reference

Every keyword supported by MasioASM, explained with side-by-side comparison with translated NASM assembly.

include

File Linking

Transforms the target .masio file into NASM, compiles it, and links it with the main executable.

// MasioASM include "math.masio"
; Generated NASM / Linker Directive ; Transformed math.masio -> math.o & linked

insert

Direct Source Inlining

Inserts needed functions from another file into the current transformed NASM file. Source .masio files are never altered; only generated NASM code changes.

// MasioASM insert "utils.masio"
; Generated NASM ; [Contents of transformed utils.masio inserted directly here]

if

Conditionals

Standard conditional statement that auto-generates jump labels and comparisons. Ends with the end keyword.

// MasioASM if rax == 0:
    mov rdi, 1
end
; Generated NASM cmp rax, 0
jne ._if_end_1
mov rdi, 1
._if_end_1:

loop

Iteration

Loops continuously until the expression becomes false. Ends with the end keyword.

// MasioASM loop rcx > 0:
    dec rcx
end
; Generated NASM ._loop_start_1:
cmp rcx, 0
jle ._loop_end_1
dec rcx
jmp ._loop_start_1
._loop_end_1:

end

Block Closure

Closes function definitions (fn), conditionals (if), and loop structures (loop).

public / private

Function Visibility

Functions are private by default. Prefix with public to export symbols globally for external linking via include.

// MasioASM public fn add_num:
    add rax, rbx
end
; Generated NASM global add_num
add_num:
    add rax, rbx
    ret

zero

Register Clearing

Shortened keyword for zeroing out a register using the idiomatic self-XOR instruction.

// MasioASM zero rax
; Generated NASM xor rax, rax

fn / FSetup / FDestroy

Functions & Framing

fn declares a function label. FSetup handles stack frame allocation (push rbp; mov rbp, rsp), and FDestroy cleans up (mov rsp, rbp; pop rbp).

// MasioASM fn calculate:
    FSetup
    FDestroy
end
; Generated NASM calculate:
    push rbp
    mov rbp, rsp
    mov rsp, rbp
    pop rbp

return

Context-Aware Exit

Intelligently determines exit vs return logic based on function context:

  • Inside _start (no value): Zeroes rdi (status 0), sets rax to 60 (sys_exit), and calls syscall.
  • Inside _start (value given): Sets rdi to value, sets rax to 60, and calls syscall.
  • Subroutine (no value): Emits NASM ret instruction.
  • Subroutine (value given): Moves value into rax return register and emits ret.
// MasioASM (_start vs subroutine) fn _start:
    return 0
end
; Generated NASM (sys_exit) _start:
    mov rdi, 0
    mov rax, 60
    syscall

print

String I/O Helper

Auto-generates string constants into the output NASM section .data and inserts the necessary Linux sys_write syscall routines.

// MasioASM print "Hello World!"
; Generated NASM Data & Syscall section .data
    msg_1 db "Hello World!", 10
    msg_1_len equ $-msg_1
section .text
    mov rax, 1  ; sys_write
    mov rdi, 1  ; stdout
    mov rsi, msg_1
    mov rdx, msg_1_len
    syscall

comments

Multi-Syntax Support

MasioASM accepts standard assembly, C, Python, Bash, and Lua comment syntaxes:

; Assembly style comment
// C / C++ style comment
# Python / Bash style comment
-- Lua style comment

MasioCLI

Command line toolchain usage for building and running project files.

# Transform .masio into .asm and compile binary $ masio build main.masio
# Transform, compile, and run immediately $ masio run main.masio
